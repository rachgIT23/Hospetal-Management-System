# Hospital Management System

A web-based Hospital Management System developed using Python, Django, Django REST Framework, HTML, CSS, JavaScript, and SQLite.

## Features
- Patient Management
- Doctor Management
- Appointment Scheduling
- Medical Records
- CRUD Operations
- REST APIs

## Technologies Used
- Python
- Django
- Django REST Framework
- HTML
- CSS
- JavaScript
- SQLite

## How to Run

1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run migrations:
   python manage.py migrate
4. Start the server:
   python manage.py runserver
